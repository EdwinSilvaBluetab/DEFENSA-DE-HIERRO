# Security Policy

Este repositorio es una demostración educativa deliberadamente vulnerable en la rama `main`.

- No desplegar la rama `main` en Internet.
- No usar datos reales, credenciales reales ni infraestructura de producción.
- La rama `fix/security-hardening` contiene las mitigaciones y pruebas de regresión.
- Los hallazgos del reto se documentan públicamente porque forman parte de una práctica controlada.
